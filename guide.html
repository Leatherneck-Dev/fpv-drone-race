FPV DRONE RACE

FPV 드론 레이스 사용 설명서

CoDrone EDU 조종기를 컴퓨터에 USB로 연결해, 드론의 눈(FPV)으로 게이트를 통과하며 기록을 겨루는 시뮬레이터입니다. 조종기 연결부터 비행, 교실 순위 화면 운영까지 순서대로 설명합니다.

주소창에 위 주소만 입력하면 됩니다(https:// 생략 가능).

수업 코드란?

순위표의 이름입니다. 같은 수업 코드를 쓰는 PC끼리 기록이 한 순위표에 모입니다. 주소에 붙일 필요 없이 화면에서 입력합니다.

🎮 시뮬레이터 (학생 PC)
메인 화면 오른쪽 위 “수업 코드” 칸에 입력 → [적용] (또는 Enter)
🏆 순위 화면 (교실 앞)
화면 오른쪽 위 “수업 코드” 칸에 입력 → [적용] (또는 Enter)
예) 11월 5일 3반 수업 → 학생 PC와 교실 앞 화면 모두 수업 코드에 1105-3반 입력
  • 학생 PC와 순위 화면의 수업 코드가 반드시 같아야 기록이 순위 화면에 나옵니다.
  • 한 번 입력한 코드는 그 PC에 저장돼서 다음에 열어도 그대로입니다. 같은 PC에서 순위 화면을 열면 자동으로 같은 코드가 됩니다.
  • 코드를 바꾸면 빈 순위표가 새로 시작됩니다. 이전 반 기록은 그 코드를 다시 입력하면 볼 수 있습니다.
  • 띄어쓰기와 특수문자(/ . #)는 자동으로 빠집니다. 아무것도 입력하지 않으면 기본 코드 class입니다.

03조종기 연결

  1. 조종기 전원을 켭니다. (실제 드론은 꺼 둔 상태)
  2. USB 케이블로 조종기를 PC에 연결합니다.
  3. Chrome/Edge로 시뮬레이터 주소를 엽니다.
  4. 메인 화면 오른쪽 CONTROLLER · 조종기의 [연결] 버튼을 누릅니다.
  5. 브라우저 창에 나오는 목록에서 조종기의 COM 포트를 고르고 [연결]을 누릅니다.
    보통 “STMicroelectronics Virtual COM Port (COM3)”처럼 표시됩니다. 번호는 PC마다 다릅니다.
  6. 상태가 초록 점 ● 조종기 연결됨 · 50Hz 수신 중 으로 바뀌면 완료입니다.
  7. 스틱 보정: 스틱에서 손을 뗀 상태로 연결하면 자동으로 가운데를 맞춥니다. 비행 중 드론이 혼자 한쪽으로 가면, 손을 뗀 채로 [보정]을 누르세요.

05시동 걸기

실제 드론처럼 시동을 걸어야 날 수 있습니다. 시동 전에는 스로틀을 올려도 뜨지 않습니다.

왼쪽 스틱 ↘
아래 + 오른쪽(안쪽)
오른쪽 스틱 ↙
아래 + 왼쪽(안쪽)
  1. 드론이 땅에 있을 때, 양쪽 스틱을 동시에 안쪽 아래로 모읍니다. (끝까지 안 밀어도 절반 정도면 됩니다)
  2. 잠깐(약 0.3초) 유지하면 화면에 시동됨이 뜨고, 아래쪽 상태가 ● 시동됨으로 바뀝니다.
  3. 스틱을 놓고, 왼쪽 스틱을 위로 올리면 이륙합니다.
  • 시동 끄기: 땅에 내려앉은 뒤 같은 동작을 한 번 더. (공중에서는 꺼지지 않습니다)
  • 키보드: Space 키로 시동 걸기/끄기
  • 출발점으로 돌아가거나(R·처음으로·추락) 연습 종류를 바꾸면 시동이 꺼진 상태로 시작합니다. 다시 시동을 걸어 주세요.

06조종 방법 (Mode 2)

CoDrone EDU와 같은 Mode 2 방식입니다.

왼쪽 스틱
↑↓ 상승 / 하강 (스로틀)
←→ 왼쪽 / 오른쪽 회전 (요)
오른쪽 스틱
↑↓ 전진 / 후진 (피치)
←→ 왼쪽 / 오른쪽 이동 (롤)
비행 팁
  • 스틱은 살짝만! 앵글 모드에서는 스틱을 놓으면 그 자리에 멈춥니다.
  • 회전할 때는 왼쪽 스틱으로 방향을 돌리면서 오른쪽 스틱으로 살짝 전진하면 부드럽게 돕니다.
  • 게이트 앞에서는 속도를 줄이고 높이부터 맞춘 뒤 통과하세요.

07레이스 규칙

  1. 시동을 걸고 이륙합니다. 타이머는 아직 0입니다.
  2. 초록색 1번 게이트를 통과하는 순간 타이머 시작!
  3. 게이트를 번호 순서대로 통과합니다. 순서를 건너뛴 게이트는 인정되지 않습니다.
  4. 마지막 게이트(FINISH)를 통과하면 완주 → 기록이 순위표에 올라갑니다. (교육용 맵 “정밀 착륙”은 H 착륙장에 착륙하면 완주)

수평 게이트, 위에서 아래로 통과

터널(헛간·컨테이너·빌딩 통로)은 입구 게이트를 통과하면 인정됩니다.

충돌

  • 살짝 부딪힘: 튕기고 흙먼지·나뭇잎·불꽃 효과. 계속 비행 가능 (결과에 “부딪힘 횟수”로 기록)
  • 세게 부딪힘·추락: 드론이 떨어진 뒤 출발점에서 처음부터 다시 (시동도 다시)

기록

  • 완주할 때마다 1줄씩 순위표에 올라갑니다. 같은 팀도 여러 번 올라갈 수 있고, 빠른 순서로 10개가 보입니다.
  • 완주 화면에 현재 순위와 팀 최고기록 비교가 나옵니다.
  • 게이트를 지날 때마다 우리 팀 최고기록보다 빠르면 −0.32, 느리면 +0.32처럼 표시됩니다.
  • 완주 후 1번 게이트로 다시 날아가면 바로 새 도전이 시작됩니다.

게임패드(Xbox 등)를 연결하면 자동으로 인식합니다. 우선순위: CoDrone 조종기 → 게임패드 → 키보드

11교실 순위 화면

  1. 교실 앞 PC에서 fpvrace.web.app/board를 Chrome으로 엽니다.
  2. 오른쪽 위 수업 코드 칸에 코드를 입력하고 [적용]을 누릅니다.
  3. F11로 전체 화면을 켭니다.
  4. 오른쪽 위가 ● LIVE 인지 확인합니다. (모든 PC 기록이 실시간으로 올라오는 상태)
  5. 필요하면 🔇 소리 꺼짐 버튼을 눌러 🔊 소리 켜짐으로 바꿉니다.

소리켜면 1위 갱신 때 팡파르, 새 기록 때 “띵동” 알림음 (연출은 소리와 상관없이 나옴)
패널 클릭그 맵 순위만 크게 보기 / 다시 클릭하면 3개 보기
기록 초기화이 수업 코드의 순위와 최근 기록을 비우고 새로 시작 (모든 PC에 반영, 이전 기록은 다시 볼 수 없음)

12수업 진행 순서 (예시)

  1. 수업 전: 수업 코드를 정합니다(예: 1105-3반). 교실 앞 PC에서 fpvrace.web.app/board를 열고, 오른쪽 위 수업 코드 칸에 입력 → [적용]. 학생들에게 주소 fpvrace.web.app와 수업 코드를 칠판에 적어 줍니다.
  2. 학생 PC: 주소를 열고 메인 화면 오른쪽 위 수업 코드 칸에 같은 코드 입력 → [적용].
  3. 연결: 실제 드론은 끄고, 조종기를 USB로 연결 → [연결] → COM 포트 선택.
  4. 팀 이름 입력 → 앵글 · 1단으로 시작 권장.
  5. 교육용 맵에서 연습 1~6을 순서대로 (별 3개 목표).
  6. 그린 필드에서 첫 완주 → 순위 화면에 이름이 올라가는지 확인.
  7. 익숙해지면 2단, 물류 창고, 메트로 시티로 도전. 잘하는 학생은 호라이즌·아크로.
  8. 다음 반은 순위 화면과 학생 PC의 수업 코드 칸만 바꾸면(예: 1105-4반) 새 순위표로 시작합니다.
팀이 바뀔 때는 팀 이름도 바꿔 주세요. 팀 이름은 PC에 저장돼 있어서, 그대로 두면 이전 팀 이름으로 기록됩니다.

13선생님 설정

config.js 파일에서 바꿉니다. 고친 뒤 사이트(fpvrace.web.app, Firebase Hosting)에 다시 배포해야 반영됩니다. 원본 파일은 GitHub 저장소에 함께 보관됩니다.

항목예시설명
room"class"화면에서 수업 코드를 입력하지 않았을 때 쓰는 기본 코드
speedLevels[1, 2, 3] → [2]고를 수 있는 속도 단계. 하나만 남기면 모두 같은 속도로 겨룸
allowedModes["angle"]고를 수 있는 비행 모드 (angle·horizon·acro)
invert{ throttle: true, ... }스틱 반전 기본값 (각 PC의 조종 설정에서도 바꿀 수 있음)
firebase(설정됨)여러 PC 기록 공유용. 지우면 각 PC에만 기록되는 로컬 모드
  • 잘못된 기록 지우기: Firebase 콘솔 → Firestore Database → rooms → 수업 코드 → runs_맵이름에서 해당 문서 삭제 (맵 이름: field, warehouse, city)
  • 저장소: github.com/Leatherneck-Dev/fpv-drone-race

14문제 해결

[연결]을 눌러도 COM 포트 목록에 조종기가 없어요
  • 조종기 전원이 켜져 있는지 확인하세요.
  • USB 케이블이 데이터용인지 확인하세요. 충전 전용 케이블은 연결이 안 됩니다. 다른 케이블·다른 USB 포트로 바꿔 보세요.
  • 다른 프로그램이 조종기를 쓰고 있지 않은지 확인하세요. (코딩 앱·다른 브라우저 탭 등 → 닫기)
  • 목록에 아무것도 없으면 Windows 장치 관리자 → “포트(COM & LPT)”에 조종기가 보이는지 확인하세요.
“이 브라우저는 조종기 연결을 지원하지 않아요”가 떠요

Chrome 또는 Edge로 열어 주세요. 또한 반드시 https:// 주소로 열어야 합니다.

연결됐는데 “응답 대기 중”에서 안 바뀌어요

조종기 전원을 껐다 켜고, [연결] 버튼을 다시 눌러 주세요(해제 후 재연결). USB를 뽑았다 다시 꽂아도 됩니다.

드론이 혼자 한쪽으로 가요

스틱에서 손을 뗀 상태로 [보정]을 누르세요. 그래도 그러면 조종 설정의 데드존을 8~10%로 올려 보세요.

스틱을 위로 올렸는데 반대로 움직여요

메뉴 → 조종 설정 → 해당 축의 반전에 체크하세요.

시동이 안 걸려요
  • 드론이 땅에 있을 때만 걸립니다.
  • 양쪽 스틱을 동시에 안쪽 아래(왼쪽 ↘, 오른쪽 ↙)로 모아 잠깐 유지하세요.
  • 화면 오른쪽 아래 스틱 표시로 스틱이 실제로 그 방향으로 가는지 확인하세요.
  • 키보드는 Space.
순위 화면에 기록이 안 떠요
  • 학생 PC와 순위 화면의 수업 코드(room)가 같은지 확인하세요.
  • 순위 화면 오른쪽 위가 LIVE인지 확인하세요. LOCAL이면 인터넷 연결 문제입니다.
  • 교육용 맵은 연습 전용이라 순위에 올라가지 않습니다.
화면이 끊기고 느려요

느린 PC는 자동으로 그래픽 품질을 낮춥니다(풀·그림자 줄임). 다른 프로그램과 브라우저 탭을 닫아 주세요. 메트로 시티가 가장 무겁습니다.

고친 내용이 반영이 안 돼요 / 예전 화면이 나와요

Ctrl + F5로 새로고침하세요. 브라우저가 예전 파일을 저장해 둔 경우입니다.

게이트까지 거리가 실제보다 멀게/가깝게 느껴져요

FPV 카메라가 넓은 각도(광각)라 실제 거리와 느낌이 다를 수 있습니다. 조종 설정의 시야각을 80° 정도로 낮추면 거리감이 자연스러워집니다.
